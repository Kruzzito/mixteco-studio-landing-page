# Mixteco Studio - Desarrollo de Software con Identidad

### [Visita el sitio oficial](https://mixtecostudio-41581.web.app/#inicio)

## Sobre el Proyecto
**Mixteco Studio** es una iniciativa de desarrollo tecnológico que busca fusionar la ingeniería de software moderna con elementos de la cultura Mixteca. Este repositorio contiene la landing page oficial que presenta nuestra visión y servicios de desarrollo de aplicaciones web y móviles.

## Hitos del Proyecto
- **App en Play Store:** Actualmente contamos con una aplicación móvil desplegada bajo el sello de Mixteco Studio.
- **Identidad Única:** Diseño visual basado en iconografía tradicional aplicada a interfaces modernas.

## Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3, JavaScript.
- **Despliegue:** Firebase Hosting.
- **Concepto:** Branding e identidad visual basada en codices y deidades Mixtecas.

## Características de la Web
- **Diseño Responsive:** Adaptabilidad completa para una navegación fluida en dispositivos móviles.
- **Arquitectura Modular:** Preparada para expandirse con un catálogo de proyectos y servicios.
- **Navegación por Anclas:** Acceso rápido a las secciones de Inicio, Servicios y Contacto.
